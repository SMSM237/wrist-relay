# Galaxy S25 Edge + Watch Ultra (2025) 검증

## 사전 설정

1. 휴대폰에 서명된 APK를 설치합니다.
2. Wrist Relay의 알림 접근과 알림 게시 권한을 허용합니다.
3. Galaxy Wearable › 워치 설정 › 알림 › 앱 알림에서 Wrist Relay를 허용합니다.
4. 같은 메뉴에서 `휴대전화 알림 무음`을 켭니다.
5. 워치의 방해 금지, 극장, 수면 모드가 꺼져 있는지 확인합니다.

## 필수 시나리오

- 감지 전 과거 알림이 목록에 나타나지 않음
- 감지 후 차량 열림·닫힘 알림이 나타남
- 같은 상시 알림 업데이트가 반복 기록되지 않음
- 감지 취소 즉시 목록과 DB 기록이 사라짐
- 워치 테스트는 휴대폰 소리 없이 워치에서만 인지됨
- 네 프리셋을 각각 테스트하고 사용자 확인 문구가 나타남
- 규칙 저장 직후 다른 기록이 삭제됨
- 선택 기록이 30분 후 삭제됨
- 앱 강제 종료·재실행 후 활성 1시간 창과 규칙이 유지됨
- 휴대폰 재부팅 후 규칙 일치 알림이 워치로 전달됨
- 제목 또는 기기 코드가 달라진 알림에서 선택 조건에 따라 일치/불일치가 예상대로 동작함
- 워치 연결 해제 시 앱이 연결 성공을 허위 표시하지 않음

## 기록할 증거

- 휴대폰/워치 소프트웨어 버전과 Galaxy Wearable 버전
- 각 프리셋의 사용자 체감 결과
- 열림/닫힘 각 10회 전달 성공률
- 휴대폰 소리·진동 발생 여부
- 실패 시 개인정보 제외 진단 문자열과 발생 시각

실기기 검증 전에는 앱 내부 문구도 `사용자 확인`까지만 표현하며 연결 또는 전달 성공을 시스템 사실로 주장하지 않습니다.
